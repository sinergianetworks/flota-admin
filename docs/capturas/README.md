Al agregar o reemplazar una captura, **no incluyas datos reales**: ni nombres de personas o clientes, ni placas, IMEIs, ubicaciones reconocibles ni logos de terceros.

Para agregar `mapa.png` al README, pon el archivo en esta carpeta y agrega una columna a la tabla de capturas del README principal.
